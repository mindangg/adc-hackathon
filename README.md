# Career Navigator

Trò chuyện → Hồ sơ nghề nghiệp → 3 hướng đi (skill gap + công cụ) → CV Word.

```bash
cp .env.example .env   # điền ANTHROPIC_API_KEY
npm install
npm run dev
```

Test bắt buộc: đi hết luồng bằng VoiceOver (Cmd+F5) hoặc NVDA, không dùng chuột.

`data/tools.json` là danh sách công cụ đã kiểm chứng — AI chỉ được gợi ý công cụ trong danh sách này.
